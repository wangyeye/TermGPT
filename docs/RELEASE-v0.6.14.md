Adds a local Notepad beside Command Library in the top-right toolbar, also available through Terminal → Notepad.

- Create and edit notes with a title, optional folder and multiline plain-text content. Save or Command-S commits changes; Cancel leaves the saved note unchanged.
- Search title, folder and content; copy full text; confirm deletion by note title.
- Notes persist locally in `workspace.json`, including Unicode and multiline content. Older configurations remain compatible. Notes are not automatically sent to AI or a terminal.

ARM/Intel packages are ad-hoc signed, not notarized; physical Intel testing is pending. Personal configuration, notes, credentials and logs are excluded from releases.

右上角常用命令库旁新增记事本图标，也可通过“终端 → 记事本”打开。

- 支持标题、可选文件夹、多行纯文本，点击保存或 ⌘S 保存，取消不修改已有笔记。
- 支持按标题、文件夹、内容搜索，复制全文，删除时显示笔记标题并确认。
- 中文及多行内容保存在本机 `workspace.json`，兼容旧配置；笔记不会自动发送给 AI 或终端。

ARM/Intel 临时签名、尚未公证，未进行 Intel 真机验证。发布包不包含个人配置、笔记、密码或日志。
