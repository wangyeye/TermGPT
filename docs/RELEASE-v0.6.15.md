Notepad and Command Library now open in separate, resizable windows. Keep both open while operating terminal, web, VNC and RDP tabs. Repeated clicks bring the existing window forward. Editors belong to their library window, and command insertion follows the selected terminal. Closing a library window does not close a terminal tab.

Notes and commands remain in the local JSON configuration. ARM/Intel packages are ad-hoc signed, not notarized; physical Intel testing is pending.
