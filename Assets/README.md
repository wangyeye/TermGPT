# TermGPT icon

Generated by the built-in imagegen tool. `AppIcon.png` is the flat source asset. `TermGPT.icns` is generated locally and excluded from the public source export.

The design uses a solid dark navy rounded square, a white terminal `>` and underscore, and a mint four-point sparkle. It has no glossy highlights, glow, bevels or drop shadows. The exterior is transparent. No third-party logo is used.

Run `./scripts/make-icon.sh` from the project root. It checks macOS, sips and iconutil, generates 16–1024 pixel icon sizes and creates ICNS. Then `./scripts/build.sh` includes the icon in the app resources and Info.plist. A newer PNG automatically regenerates the ICNS during builds.

Final imagegen edit prompt:

> Use case: style-transfer. Edit target: the supplied TermGPT macOS app icon. Make a truly flat minimalist icon, preserving its recognizable composition: a white terminal > chevron at lower left, a white underscore at lower right, and a mint four-point sparkle in the upper right, all inside a dark navy rounded square. Uniform solid fills only. Remove ALL highlights, gloss, gradients, glow, bevels, reflections, drop shadows, outlines and 3D depth. Crisp smooth antialiased edges, balanced generous padding, readable at 16px. Rounded-square silhouette with clean transparent exterior. Same basic positions and palette, but entirely two-dimensional vector-like appearance. No text beyond the > and underscore, no watermark. Output a square high resolution PNG with real transparency.
