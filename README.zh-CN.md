# TermGPT

[English](README.md) | **简体中文**

原生 macOS 工作台，集成终端、AI 助手、远程桌面和内置网页。使用 SwiftUI、AppKit、SwiftTerm 和 WebKit 构建。

## 下载与安装

从 [GitHub Releases](https://github.com/wangyeye/TermGPT/releases/latest) 下载最新版。

| Mac 类型 | 安装包 |
| --- | --- |
| Apple Silicon（M 系列） | `TermGPT-macOS-arm64.zip` |
| Intel | `TermGPT-macOS-x86_64.zip` |

需要 **macOS 13 或更新版本**。解压 ZIP，将 `TermGPT.app` 移到“应用程序”。运行时无需 Homebrew 或额外桌面客户端。发行版提供 `SHA256SUMS` 和桌面组件对应源码。

安装包采用临时签名，**尚未进行 Developer ID 签名或公证**。Intel 包已交叉编译并检查架构，尚未在实体 Intel Mac 上验证。

| 模块 | 功能 |
| --- | --- |

| 标签页 | 中间区域打开连接；拖动排序、关闭全部、关闭右侧 |

### 连接诊断、声音状态与重连

SSH/RDP/VNC 标签右键提供**重连、断线自动重连、连接诊断**。连接结束后重连会保留原标签；自动重连默认关闭，仅对当前标签生效，意外断线后最多尝试三次，间隔为 3/6/9 秒。认证、权限、证书错误停止重试；关闭标签或关闭选项取消待执行的重连。这些临时选项不保存到配置。

诊断只检查 TCP 端口，不尝试登录。SSH config 别名通过系统 `ssh -G` 解析；端口可达不代表密码、证书或协议正确。根据已有证据，区分网络、DNS、认证、证书/协议和权限问题；远程桌面失败面板直接提供诊断与重连。日志只保存在本机，不记录密码、剪贴板和画面。

桌面标签右键显示声音状态和**静音/取消静音**。等待服务端音频不代表服务端已安装音频模块；VNC 仅提示音表示没有协商出连续音频。静音只影响当前连接（包括 VNC 提示音），同标签重连保留静音设置。不新增桌面顶部状态栏。

### 查找与快速打开

侧栏支持按名称、地址、协议、文件夹搜索，多个关键词需全部匹配；搜索时自动展开匹配文件夹，不改变书签排序。**⌘P** 在任意布局打开快速打开窗口，可搜索、上下选择并回车打开，也可点击整行；已打开标签直接切换，书签条目沿用重复标签选择提示，Esc 关闭。最近连接记录十个最近打开或切换的书签，包括连接尝试，不代表认证成功。`workspace.json` 仅保存书签 ID；清空历史不删除书签，书签改名会同步显示，删除后不再出现。

## 快速上手

1. 打开软件使用**本地 Shell**，或点击“连接书签”旁的 **+**。
2. 选择 SSH、VNC、RDP 或 WEB，填写名称和连接信息后保存。WEB 使用完整 HTTP/HTTPS URL；SSH 支持 config/Agent、保存密码或私钥；VNC/RDP 可保存登录信息。
3. 点击书签所在行即可打开。同一书签已有标签时，可选择**切换到已有标签**、**打开新标签**或取消。按书签身份匹配，不按 URL 去重。
4. 通过 `…` 修改/删除、移动文件夹或上移/下移。文件夹右键菜单可排序；文件夹管理可新增、重命名和删除。删除文件夹会将书签移到“未分类”。
5. **设置**中可连接 AI、选择语言/主题、配置脱敏和网页地址栏。语言默认跟随系统：中文系统使用中文，未支持语言使用英语。
6. 右上角布局按钮控制书签栏和 AI 助手；SFTP 使用独立文件夹按钮。

### AI 助手

设置中点击 **Continue with ChatGPT** 登录，账户、套餐、额度和模型由服务端决定。OpenAI API 是 Advanced / Other Providers 中的独立选项。使用 Ollama 或 LM Studio 时，先启动本地服务，再填写可用模型。

聊天分别显示分析上下文来源和当前命令执行目标。上下文可选自动、关闭、选中文字、最近若干行或整个会话，并可固定。AI 不会自行执行命令。标记为 Shell 的代码块提供复制/填入/执行；日志、引用和其他代码仅提供复制。填入不按回车；需要确认的命令点击确认执行，无需输入 RUN。

回答生成时可自由滚动和复制命令，不强制跳到最新内容。切换聊天默认显示最新消息。支持重命名/删除、可选本地历史和导出。发送前按设置自动脱敏或保留原文，不弹额外确认框。

### WEB 书签

WEB 标签右键选择“关闭其他标签”，保留该标签并关闭其他中间标签，包括终端和远程桌面连接。

浏览器标签页右键菜单提供“强制刷新”，从服务器重新加载页面并绕过缓存，地址栏隐藏时也可使用。

导航和地址栏**默认隐藏**。设置中开启“显示网页地址栏”，即可使用前进、后退、刷新和 URL 输入框；切换设置不重新加载网页。

HTTP Basic/Digest 验证会弹出用户名和密码框。勾选**保存密码**后，重启也可自动登录；按协议、主机、端口、认证域和方式隔离凭据。普通用户名/密码表单提交时会询问是否保存。选择保存并自动填充后，下次访问同一网站自动填入，但不自动提交。支持动态表单；第三方嵌入页面、通行密钥、多步骤或非标准控件可能仍需手动输入。JavaScript 密码弹窗（包括 noVNC）也支持可选保存和预填。

HTTPS 证书不受信任时显示主机、证书名称和 SHA-256 指纹，可选**仅本次信任**、**始终信任**或取消。始终信任保存此主机/端口的指纹，证书变化后重新询问；其他主机继续使用正常验证。

网页输入关闭拼写检查、自动纠正和自动大写；macOS 15 及以上关闭系统书写工具。网页自身提示和输入法候选词仍由网页或输入法控制。网站会话/Cookie 由 WebKit 在本机保存。

### 文件传输

- **SFTP：**选中书签打开的 SSH 标签，使用顶部文件夹按钮或标签右键菜单。支持目录浏览、单文件上传/下载、进度、错误和取消。面板固定连接打开时的主机；无法识别在本地 Shell 中手动启动的 SSH。
- **ZMODEM：**远端运行 `sz 文件名` 选择本地下载目录；运行 `rz` 选择上传文件。远端需要安装 rz/sz，Mac 组件已内置。传输期间暂停键盘输入和 AI 命令操作。
- SFTP 同名覆盖需要确认。传输使用临时文件，中断上传可能留下远端 `.partial`。暂不支持递归目录传输或远程编辑。

### VNC 与 RDP

桌面在中间标签页显示。服务器支持时分辨率随可见面板调整；不支持时等比例缩放。RDP 使用 TLS/NLA，可选仅本次信任/始终信任/取消。始终信任将证书指纹绑定到书签主机/端口，变化后重新询问。

剪贴板同步可选，仅同步当前桌面标签的文本，最大 1 MiB。RDP 支持 Unicode；VNC 中文需要扩展剪贴板。传统 VNC 认证不加密桌面流量。暂不包含磁盘映射、网关、多显示器或文件/图片剪贴板。

远端声音自动通过 Mac 当前输出设备播放。RDP 需要服务端启用音频重定向；xrdp 还需安装对应音频模块。VNC 支持标准提示音，以及服务端提供 QEMU Audio 扩展时的连续声音；没有此扩展的普通 VNC 服务无法传送声音。不包含麦克风转发。

## 本地数据与隐私

文件位于 `~/Library/Application Support/TermGPT/`：

| 路径 | 内容 |
| --- | --- |
| `workspace.json` | 书签、文件夹、顺序、设置和可选聊天历史 |
| `credentials.json` | ChatGPT Token、API Key、连接/网页密码和证书指纹 |
| `Logs/` | 本地远程桌面诊断日志 |

凭据采用**明文 JSON**，目录/文件权限为 0700/0600，不使用钥匙串。请保持这些文件私有。JSON 原子写入，格式损坏时不静默覆盖；不自动迁移旧钥匙串数据。

源码和安装包不包含个人配置、凭据、聊天、截图或日志；诊断不会自动上传。AI 请求会将所选消息/历史/上下文交给当前供应商。默认开启脱敏，但不能识别所有秘密；导出默认脱敏。WebKit 单独维护本地网站存储。

VNC/RDP 桌面直接铺满标签页，不显示顶部状态栏。右键桌面标签页可查看连接状态、打开日志、验证证书及发送 RDP Ctrl+Alt+Del。连接中或失败时会在桌面上显示提示。

桌面日志不记录密码、配置中的主机/用户名/域、剪贴板或画面；最多 20 次连接，每份 2 MiB。可使用标签页日志菜单和 macOS“控制台”的崩溃报告排查失败。

## 构建、测试与发布

### 终端搜索、命令库和工作区恢复

- 选中已启动的终端，按 **⌘F** 搜索并定位、高亮当前匹配；上下按钮或回车循环切换。`Aa` 区分大小写，`.*` 使用正则表达式；刷新可重新搜索新输出，Esc 关闭。按终端物理行搜索，折行分别匹配，最多显示一万条匹配。
- **终端 → 常用命令库（⌘⇧K）** 支持新增、编辑、删除和搜索名称、文件夹、命令及备注；AI 命令卡也可点击“收藏”。任意命令可复制，单行命令可填入当前终端而不执行，多行命令仅复制。
- **设置 → 启动时恢复工作区** 默认开启。标签顺序、选中标签与已有布局设置保存在本机 `workspace.json`；恢复的标签需点击“恢复连接”才启动。书签更新在重启后应用，已删除书签跳过。不恢复终端输出、运行进程或远程会话。关闭设置后，启动时创建新的本地终端。
- 命令及工作区引用仅本机保存，不进入发布包。命令以明文存于本地配置，请勿在其中写入密码。

详见[开发与脚本指南](docs/DEVELOPMENT.zh-CN.md)，包含环境检查、脚本作用、测试、诊断和发布步骤。

```bash
./scripts/check-environment.sh
./scripts/build.sh
./scripts/run.sh
```

构建需要 macOS 13+、Swift 5.9+、Command Line Tools 和系统 SSH/zsh；桌面组件还需要 CMake 3.20+、Python 3.12+、make、Perl。测试需要完整 Xcode/XCTest；无需 Rust、Node 或 npm。
